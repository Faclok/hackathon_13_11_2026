# Иллюстрации наград

- `1/bgs/` — фоны (9).
- `2/bashkortostan_pets/` — питомцы (9).
- `3/items/` — предметы (9).
- `4/hats/` — новые головные уборы (3); прежние SVG остаются в `components/HatOverlay.tsx`.
- `5/frames/` — новые рамки (3); прежние рамки остаются в `personalization.css`.

В каждой номерной папке есть `description.txt`. Используются SVG из вложенных папок; существующие дубликаты в корне папок не являются источником для приложения.

Откройте `preview.html` в браузере, чтобы посмотреть все 15 новых наград, включая фоны и наложение шапок и рамок на аватарку.

Новые фоны имеют `viewBox="0 0 520 420"` и полностью заполняют кадр. Питомцы и предметы имеют `viewBox="0 0 300 300"`, шапки — `0 0 300 155`, рамки — `0 0 300 300`; у этих украшений фон прозрачный. Рамки размещаются поверх аватарки с отступом `-8%`; шапки используют общую посадку `.avatar-hat`. Внешние ресурсы, шрифты, скрипты и растровые вставки в SVG не используются.

Название, описание, редкость и импорт SVG задаются в `src/mocks/prizes.ts`. Массив `culturalPrizes` подключён к `caseDecorations` в `src/mocks/customization.ts`. Идентификатор, тип и редкость должны совпадать с `RewardCatalog.Items` в `src/main-api/src/BashkirSchool.Infrastructure/RewardCatalog.cs`.

Фоны выпадают из `case_bg`, шапки и рамки — из своих кейсов, питомцы и предметы — из общего `case_pet`. В каждой новой тройке по одному редкому, эпическому и легендарному предмету. Общие веса редкостей не меняются.
