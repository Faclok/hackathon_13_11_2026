# `PLAN.md` — Frontend-план платформы «Башкирская языковая школа»

> Коллекция `src/assets/prizes`: 18 SVG-наград с описаниями в `src/mocks/prizes.ts` (6 фонов, 6 питомцев, 6 предметов). В `/wheel` четыре кейса; `case_pet` «Питомцы и предметы» объединяет шесть новых питомцев и шесть культурных предметов через `dropTypes`. Отдельного культурного кейса нет. Старые четыре питомца исключены из выпадения; их данные сохранены только для ранее полученных наград. Сохранённые результаты прежнего `case_item` открываются как результат объединённого кейса. Редкость выбирается с общим весом уровня, предметы внутри уровня равновероятны; отсутствующие уровни исключаются из нормализации. Шансы в «Что внутри» соответствуют розыгрышу. Иллюстрации используются в инвентаре, открытии кейсов, профиле и рейтинге. Награды не выдаются бесплатно при загрузке и не покупаются напрямую.

> Актуализация от 15.11.2026: доступ к Боссу определяется сервером за каждые пять завершённых личных уровней, независимо от звания. `/learn` и `/boss` используют `/api/learning/*`; подробности — `LEARNING-INTEGRATION.md`. Старое описание доступа по званию и локальных наград ниже относится к прежнему моковому сценарию.

> Актуализация механики от 15.11.2026: `/inventory` — инвентарь только принадлежащих игроку предметов, `/shop` перенаправляет в него. `/wheel` — четыре кейса из модуля `castomization-page`: головные уборы, рамки, фоны, питомцы. Монеты единые с основным профилем; за 10 монет покупается только универсальный ключ, одно открытие расходует один ключ. Дубликат приносит 3 монеты. Прямой покупки украшений больше нет. Все предметы и применённое оформление используют основной Zustand store; отдельное сохранение и баланс исходного модуля не используются. За завершённый учебный уровень начисляется целая часть числа вопросов, делённого на 3; каждые пять уровней дают один накапливаемый Меч для входа к Боссу. Ответ Боссу приносит 1 монету, подтверждённый большинством или экспертом ответ — ещё 4. Задания преподавателя выдаются первыми и оформлены отдельно от случайных. Дневная карточка открывает мини-игру; в Боссе три фразы. Эти уточнения заменяют соответствующие пункты исходного плана ниже.

## 0. Контекст из ТЗ (что обязательно должно быть видно)

- **Полный цикл:** материалы → фрагменты → ежедневное задание → согласование → фиксация перевода.
- **Ежедневное задание:** фрагмент на башкирском + автоперевод, иногда с ошибкой. Пользователь подтверждает или исправляет.
- **Геймификация:** баллы, уровни, бейджи, рейтинги (по задачам, по серии, по школам/классам — в MVP упрощаем до личного рейтинга), достижения.
- **Данные:** у каждого фрагмента есть `fragment_id, text_ba, lang_pair, translation, source, confirmed, status`.
- **Профиль:** языковые пары, статистика, достижения.

> В MVP-фронте мы не делаем реальную БД, API, Telegram-бота, TTS и экспертную модерацию — только визуал + моки. Но структуры данных и тексты интерфейса уже соответствуют ТЗ, чтобы бэкенд сел без переделок.

### 4.3. `/daily` — Ежедневное задание (из ТЗ)

**Логика из ТЗ:** пользователь получает фрагмент + автоперевод; иногда перевод намеренно с ошибкой; задача — подтвердить корректный или исправить.

**Шаги (wizard):**

1. **Интро:**
   - «Ежедневное задание»
   - «Подтверди перевод или исправь ошибку».
   - Кнопка «Начать».

2. **Карточка фрагмента:**
   - Сверху — метка источника: `Источник: «Урал-батыр», глава 2` (поле `source`).
   - Башкирский текст крупно.
   - Ниже — блок «Автоперевод» на русском.
   - Две кнопки:
     - ✅ **«Перевод верный»** (primary) — фиксирует подтверждение.
     - ✏️ **«Исправить перевод»** — раскрывает textarea с текущим переводом, пользователь правит, жмёт «Отправить».
   - Кнопка `⚠ Ошибка в задании` (мелкая, под блоком) — открывает модалку с textarea и кнопкой «Отправить». Сохраняет в `userStore.reportIssue()`, показывает Toast «Спасибо! Мы проверим».
   - После ответа: нейтральный фидбек «Спасибо! Ваш ответ учтён» + кнопка «Дальше».
   - **Правильный/неправильный ответ не подсвечиваем** — это соответствует ТЗ (согласование по большинству).

3. **Итог дня:**
   - «Задание выполнено!» + награды: +20 XP, +10 🪙, +1 к серии.
   - Кнопки: «На главную», «К рейтингу».

**Моки:** массив `DailyFragment { id, textBa, autoTranslation, source, hasError }` — 7 штук, по одному на день.

### 4.5. `/lesson/:lessonId` — Упражнения (3 типа)

**Шапка:** «✕» (выход с подтверждением), `ProgressBar` (например, 3/8).

**Три типа упражнений (ровно по твоему ответу):**

| Тип | Что показываем | Что делает пользователь |
|-----|----------------|--------------------------|
| `choice` | Фраза на башкирском + 4 варианта на русском | Выбирает один → «Проверить» |
| `match` | 3 строки на башкирском + 3 на русском (перемешаны) | Тапает пару баш↔рус. Все 3 пары собраны → автопроверка |
| `order` | Русское предложение дано сверху. Внизу перемешанные башкирские слова | Тапает слова в нужном порядке → «Проверить» |

**Общее поведение:**
- После «Проверить»: правильный ответ — зелёная подсветка, ошибка — красная + показ верного варианта (для учебных упражнений это ок).
- Кнопка «Продолжить» → следующее упражнение.
- Кнопка `⚠ Ошибка в задании` внизу каждого экрана — модалка + Toast.
- Начисление: +XP и +монеты за верные ответы (`addXp`, `addCoins`).

**Критерий приёмки:** все 3 типа работают без ошибок логики, прогресс-бар доходит до конца.

### 4.7. `/boss` — БОСС-испытание (рейтинговый перевод)

**Смысл:** проверка перевода без «правильного ответа» — оценивается выбор сообщества. Полностью по твоему описанию.

**Шаг 1 — Интро босса:**
- Иллюстрация/маска «Хан перевода» / «Бәйге».
- Правила: «Дана фраза на башкирском. Выбери самый популярный перевод или предложи свой. Правильного ответа нет — есть мнение сообщества».
- Кнопка «Начать».

**Шаг 2 — Раунд (10 фраз):**
- Прогресс `3/10`.
- Фраза на башкирском крупно.
- **3 варианта перевода на русский** + 4-я опция **«Предложить свой перевод»** → textarea + кнопка «Отправить».
- После выбора:
  - **НЕ показываем правильный ответ.**
  - Нейтральный фидбек: «Ответ принят ✅» + (опционально) полоса распределения голосов `42% / 33% / 25%`.
  - Кнопка «Дальше».
- Свой вариант: «Ваш перевод добавлен в голосование ✅».

**Шаг 3 — Результат:**
- «Испытание пройдено!» + счёт совпадений с популярным вариантом.
- Награды: +100 XP, +50 🪙, **трофей «Хан перевода»** (анимация).
- Кнопки: «В рейтинг» / «Ещё раз» / «На главную».

**Мок:** 10 объектов `BossPhrase { id, bashkir, options: [{id, ru, votes}], totalVotes }`.

**Критерий приёмки:** нигде не подсвечен «правильный» ответ; свой перевод принимается и сохраняется.

### 4.9. `/profile` — Профиль

**Состав:**
- Шапка: аватар (с рамкой + фоном), ник, уровень, XP-бар. **Рядом с аватаром — все купленные предметы** (маленькие иконки, клик → tooltip с названием).
- **Звания на башкирском** — список с требованиями (серия + задачи):
  ```
  Яңы башлаусы   — 0 задач
  Уҡыусы         — 10 задач
  Тырыш          — 50 задач + серия 3
  Белгес         — 100 задач + серия 7
  Оста           — 250 задач + серия 14
  Батыр          — 500 задач + серия 30
  Аҡыл эйәһе     — 1000 задач + серия 60
  ```
  Текущее звание выделено, следующие — серые с прогрессом.
- **Статистика (4 плашки):** серия 🔥 / монеты 🪙 / решено задач / точность %.
- **Языковые пары:** «Башкирский ↔ Русский» (из ТЗ). В MVP — статичная плашка, без переключения.
- **Витрина трофеев:** сетка (полученные цветные, неполученные серые с условием).
- Кнопка «Выйти» → очистка store → `/login`.

## 5. Модели данных (моки)

```ts
// src/types/index.ts
export interface User {
  id: string; nick: string; avatarUrl: string;
  level: number; xp: number; coins: number;
  streak: number; tasksSolved: number; accuracy: number;
  trophyIds: string[];
  ownedDecorationIds: string[];
  backgroundId?: string; frameId?: string;

## 9. Демо-сценарий и приёмка

**За 2 минуты жюри должно увидеть:**
1. Вход → главная **как в макете** (ежедневное задание, серия, мини-игра).
2. «Начать задание» → `/daily`: подтвердить перевод, один раз исправить, отправить «Ошибка в задании» (Toast).
3. «Играть» → урок с 3 типами упражнений → результат с наградами.
4. «Испытание Босса» → 10 фраз, один раз свой перевод → трофей.
5. «Турнирная таблица» → переключить глобальная/месячная и задачи/серия, топ-5 крупнее с фонами и трофеями, найти себя.
6. «Магазин» → открыть «О предмете», купить фон → в профиле предмет у аватара и в рейтинге.
7. «Барабан» → заглушка.
8. Профиль → звания на башкирском с требованиями, купленные предметы у аватара.

**Чек-лист:**
- [ ] Главная визуально совпадает с макетом
- [ ] Только mobile-вёрстка (390px), нет горизонтального скролла
- [ ] Работает фейковый вход, данные сохраняются
- [ ] 3 типа упражнений работают
- [ ] `/daily`: подтвердить / исправить / сообщить об ошибке
- [ ] Босс: 3 варианта + свой, «правильный» не подсвечивается
- [ ] Рейтинг: global/monthly × tasks/streak, топ-5 крупнее с персонализацией
- [ ] Профиль: звания на башкирском с требованиями + купленные предметы у аватара
- [ ] Магазин: сетка 2 колонки, описания, часть предметов только из барабана
- [ ] `/wheel` — заглушка, кнопка на главной ведёт туда
- [ ] `npm run build` без ошибок, нет падений в консоли
