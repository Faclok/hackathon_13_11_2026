# Клиент Башперевода

Основной React-интерфейс находится в `src/` и открывается по `/`.

Восстановленный рабочий кабинет находится целиком в [`test/`](test/README.md) и открывается по `/test/`. Его исходники, стили и инструкция независимы от основного интерфейса.

Общие `vite.config.js`, `Dockerfile` и `nginx.conf` собирают и обслуживают оба интерфейса. Сборка: `npm ci`, затем `npm run build`. Разработка: `npm run dev`.

Главная страница использует серверный профиль, баланс, инвентарь, кейсы и рейтинг. Временный вход — username через `POST /auth/username`; сессия обновляется через `/auth/refresh`. Для локального запуска основного API включите `Demo__UsernameLoginEnabled=true` (в основном Compose уже включено). Экраны «Босс» и «Учить» используют `/api/learning/*`; подробности и ограничения проверки — в [LEARNING-INTEGRATION.md](LEARNING-INTEGRATION.md).
