# Клиент Башперевода

Рабочий кабинет существующего ядра и LMS. Открывается на `/`, без отдельного режима или маршрута test. Боковое меню показывает задачи выбранного рабочего пространства; на экране открыт один раздел. На главной странице — следующий шаг.

- [Инструкция и полный сквозной сценарий](public/USAGE.md) — доступна также на сайте по `/USAGE.md`.
- `src/main.jsx` — вход приложения.
- `src/workspace.js` — запросы, действия, переключение аккаунтов, ротация сессий.
- `src/workspace-layout.js` — страницы и формы.
- `src/workspace-view.js` — навигация, рабочие пространства, понятные результаты и выбор по названиям.
- `src/workspace.css` — адаптивное оформление кабинета.
- `vite.config.js` — proxy для локальной разработки.

Сборка: `npm ci`, `npm run build`. Разработка: `npm run dev`. Существующий Dockerfile собирает этот клиент без изменения конфигурации развёртывания.

Пароли и серверные секреты в исходниках не задаются. Клиент использует относительные API-пути; авторизацию и области доступа проверяет сервер.

Выбор «Администратор», «Эксперт» и других пространств меняет только навигацию, не выдаёт права. JSON и журнал запросов находятся в сворачиваемых технических разделах. Порог согласования и правила обучения не менялись.
