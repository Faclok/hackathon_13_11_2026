# Клиент Башперевода

Подробности учебной интеграции — в [LEARNING-INTEGRATION.md](LEARNING-INTEGRATION.md).

Основной React-интерфейс находится в `src/` и открывается по `/`.

Привязка Telegram находится в профиле (`/profile#telegram`) основного интерфейса. «Авторизоваться в Telegram» использует текущую сессию, получает одноразовую ссылку через `POST /api/me/telegram-link` и открывает бота с ключом в `/start`. Там же можно отвязать Telegram через `DELETE /api/me/telegram-link`. Отдельная страница `telegram.html` удалена; старый адрес перенаправляет в профиль. Кабинет `test/` для этого сценария не используется.

Восстановленный рабочий кабинет находится целиком в [`test/`](test/README.md) и открывается по `/test/`. Его исходники, стили и инструкция независимы от основного интерфейса.

Общие `vite.config.js`, `Dockerfile` и `nginx.conf` собирают и обслуживают оба интерфейса. Сборка: `npm ci`, затем `npm run build`. Разработка: `npm run dev`.

Главная страница использует серверный профиль, баланс, инвентарь, кейсы и рейтинг. Временный вход — username через `POST /auth/username`; сессия обновляется через `/auth/refresh`. Для локального запуска основного API включите `Demo__UsernameLoginEnabled=true` (в основном Compose уже включено). Экраны «Учить» и «Босс» используют `/api/learning/*`: личные уровни, шесть видов вопросов, серверный прогресс и три проверки перевода босса. Старые `/lesson/*` перенаправляют в `/learn`; локальные учебные награды через эти маршруты недоступны.

Mini App открывает этот же интерфейс. При запуске из Telegram выполняется POST /auth/telegram-mini-app с подписанным initData; повторный ввод имени/пароля не нужен. Аккаунт определяется существующей Telegram-привязкой, а токены Mini App хранятся в памяти отдельно от сессии браузера. Рейтинг открывается по /leaderboard?miniapp=1, весь сайт — по /?miniapp=1. Настройки и ограничения проверки — в [README бота](../src/telegram-bot/README.md).
