## P0 — сделать реальный учебный цикл в основном UI

- [ ] Ввести DTO урока/упражнения и слой запросов вместо `getLessons` из моков для реального сценария. Обрабатывать 204, auth, ошибки и отмену/устаревание запросов при смене аккаунта. Готово: экран отображает серверный урок, после перезагрузки прогресс совпадает с API.
- [ ] Перенести шесть механик в React через реестр `(kind, schemaVersion)` и отдельные сборщики ответов. Готово: каждый вид отправляет только свой `answer`; у неподдерживаемого вида/версии нет отправки; неправильный prompt не ломает весь экран.
- [ ] Убрать зависимость реальных упражнений от локальных `correct/correctOrder`, подсказок правильных пар и повторной попытки после `recognized=false`. Готово: результат определяет API, любой сохранённый ответ блокирует упражнение, другой ответ не отправляется как новая попытка.
- [ ] Подключить дневного босса и общий renderer трёх режимов review. Готово: упражнения открывают босса, 204 сверяется с `bossCompleted`, create не показывает Confirm, choice использует ID выбранного варианта, результат нейтральный.
- [ ] Согласовать навигацию: карта моковых юнитов и реальные дневные уроки не имеют готового взаимного соответствия. Готово: определён вход в серверный урок и поведение `/learn`, `/lesson/:lessonId`, `/daily`, `/boss`; UI не ищет серверный lesson по ID мока.
