# Рабочий кабинет Башперевода — `/test/`

Основной React-интерфейс открывается на `/`. Рабочий кабинет существующего ядра и LMS доступен отдельно по `/test/`. Боковое меню кабинета показывает задачи выбранного рабочего пространства; на экране открыт один раздел.

Кабинет сохранён из последнего коммита NickFeD перед заменой фронтенда: `e8347fe` (после `8bcd17b`, «пред реализация»). После слияния `14e74a6` точка входа переключилась на React. Теперь все файлы кабинета собраны в `client/test/`. Страница `index.html` запускает локальный `src/workspace.js`; общий Vite собирает оба интерфейса в один `client/dist`.

- [Инструкция и полный сквозной сценарий](USAGE.md) — доступна также по ссылке в разделе «Как пользоваться» кабинета.
- `index.html` — вход рабочего кабинета по `/test/`.
- `src/workspace.js` — запросы, действия, переключение аккаунтов, ротация сессий.
- `src/workspace-layout.js` — страницы и формы.
- `src/workspace-view.js` — навигация, рабочие пространства, понятные результаты и выбор по названиям.
- `src/workspace.css` — адаптивное оформление кабинета.
- `../vite.config.js` — общая сборка и proxy для локальной разработки.

Из каталога `client`: `npm ci`, `npm run build`. Разработка: `npm run dev`. Существующий Dockerfile собирает оба интерфейса.

Пароли и серверные секреты в исходниках не задаются. Клиент использует относительные API-пути; авторизацию и области доступа проверяет сервер.

Выбор «Администратор», «Эксперт» и других пространств меняет только навигацию, не выдаёт права. JSON и журнал запросов находятся в сворачиваемых технических разделах. Порог согласования и правила обучения не менялись.
