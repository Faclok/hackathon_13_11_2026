## Правила реализации

- Сервер хранит прогресс и определяет правильность; никаких локальных наград.
- Экран завершения берёт `coinsAwarded` и `xpAwarded` из квитанции ответа; при восстановлении — из истории уровня.
- Ответ Боссу даёт 40 XP вместе с 1 монетой, подтверждение правильности — ещё 20 XP и 4 монеты. Отложенные результаты хранятся до закрытия уведомления.
- `/learning/current` возвращает только текущий вопрос. После ответа перечитать.
- Сохранять attemptToken и неизменённый ответ для безопасного повтора при обрыве.
- Ошибочный ответ переносится в конец очереди. Показывать результат перед продолжением.
- Завершение уровня показывать отдельно; следующий создавать по кнопке.
- Поддержать все шесть видов: перевод, диктант, перевод аудио, пропуск слова,
  порядок слов, сопоставление пяти пар. Не угадывать ключ ответа на клиенте.
- Босс доступен за каждые пять уровней, правила званий из старого UI устарели.
- Босс: перевод с нуля, подтверждение, выбор перевода, собственное исправление.
- `204`, отсутствие материала, просроченная выдача, `409`, ошибки сети и сессии
  должны иметь понятные состояния и действие восстановления.
- Старые `/lesson/*` направить в новый сценарий, чтобы моки не выдавали награды.

## Результат и проверка

Основной интерфейс получает прогресс и историю с сервера. Уровень выдаёт один
вопрос; после каждого ответа текущий вопрос перечитывается. Ошибка возвращает
вопрос в конец серверной очереди, а после завершения следующий уровень
создаётся только по кнопке. Шесть видов упражнений собраны в
`src/components/LearningExercise.tsx`. Токен и отправляемый ответ временно
сохраняются в `sessionStorage` по ID участника для безопасного повтора.

Босс использует серверную возможность за каждые пять уровней, поддерживает
создание, подтверждение, выбор и исправление перевода. Пропуск не увеличивает
счётчик трёх фрагментов. Вознаграждения выдаёт сервер; локальная выдача в
учебном сценарии удалена. Старые `/lesson/*` и `/daily` перенаправляются на
`/learn`.
