# Подключение Learn и Boss к API

Задача от 14.11.2026: заменить учебные моки настоящим прохождением личных
уровней на `/learn` и трёх переводов Босса на `/boss`. Сохранить оформление
текущего React-приложения. Старый `client/test` использовать как справочник
типов упражнений, не переносить устаревшие дневные маршруты.

## Источники истины

- `src/main-api/docs/LEVELS.md` — последовательность, ошибки, доступ к Боссу.
- `src/main-api/docs/EXERCISE-API.md` — prompt/answer для каждого вида.
- `src/main-api/src/BashkirSchool.Application/LevelContracts.cs` — DTO.
- `src/main-api/src/BashkirSchool.Application/LearningContracts.cs` — упражнения.
- `src/main-api/src/BashkirSchool.Application/Contracts.cs` — ответы проверки.
- `client/test/src/exercise-view.js` и `client/test/LESSON-INTEGRATION.md` — старый UI.
- `client/src/api/session.ts` — JWT, обновление сессии, HTTP-ошибки.

## Правила реализации

- Сервер хранит прогресс и определяет правильность; никаких локальных наград.
- `/learning/current` возвращает только текущий вопрос. После ответа перечитать.
- Сохранять attemptToken и неизменённый ответ для безопасного повтора при обрыве.
- Ошибочный ответ переносится в конец очереди. Показывать результат перед продолжением.
- Завершение уровня показывать отдельно; следующий создавать по кнопке.
- Поддержать все шесть видов: перевод, диктант, перевод аудио, пропуск слова,
  порядок слов, сопоставление пяти пар. Не угадывать ключ ответа на клиенте.
- Босс доступен за каждые пять уровней, правила званий из старого UI устарели.
- Босс: перевод с нуля, подтверждение, выбор перевода, собственное исправление.
- `204`, отсутствие материала, просроченная выдача, `409`, ошибки сети и сессии
  должны иметь понятные состояния и действие восстановления.
- Старые `/lesson/*` направить в новый сценарий, чтобы моки не выдавали награды.

## Визуальное направление

Сохранить Inter, зелёный #3C9A3C, тёмно-зелёный #2E7D32, фон #F3F8F3,
белые поверхности и индиго #6366F1 из текущего UI. Основной элемент — текущий
вопрос с крупным башкирским текстом и удобными кнопками. Над ним номер уровня
и прогресс, под ним результат и продолжение. На Learn также общие числа
и история уровней; у Босса — три последовательных шага. Верстка от мобильного
экрана, видимый фокус, доступные подписи и управление с клавиатуры.
