## О проекте

«Башперевод» соединяет изучение башкирского языка с накоплением проверенной базы переводов. Участники проходят уроки и предлагают варианты перевода; преподаватели создают классы и задания; экспертный кабинет помогает разбирать спорные случаи. Решение охватывает веб-платформу, API, Telegram-бота и экспорт учебного курса в SCORM 1.2.

| Часть | Что делает | Код |
| --- | --- | --- |
| Платформа | Уроки, упражнения, переводы, профиль и игровые механики | [`client/`](client/) |
| Кабинет преподавателя | Классы, задания, ответы, отчёты и CSV | [`lms-client/`](lms-client/), [`src/lms-api/`](src/lms-api/) |
| Кабинет эксперта | Очередь переводов, решения и импорт CSV | [`expert-client/`](expert-client/), [`src/expert-api/`](src/expert-api/) |
| Ядро | Аккаунты, права, согласование переводов и API | [`src/main-api/`](src/main-api/) |
| Telegram-бот | Личные уровни и босс в чате; рейтинг и сайт через Mini App без повторного входа | [`src/telegram-bot/`](src/telegram-bot/) |
| SCORM 1.2 | Обёртка вводного курса для совместимой LMS | [`scorm/`](scorm/) |

**Стек:** React, Vite, TypeScript, .NET 10, PostgreSQL, Node.js, Docker Compose, Nginx и Caddy.

Пользователь работает в основном приложении или Telegram. Кабинет преподавателя и экспертный кабинет обращаются к тому же ядру аккаунтов и переводов; LMS хранит свои классы и отчёты отдельно. Nginx направляет запросы по домену к нужному клиенту и API.

## Быстрый старт

Понадобятся Docker Engine с Compose V2, домен с DNS-записями для трёх сайтов и свободные порты 80/443. Подробные варианты для своего Caddy и Coolify описаны в [инструкции по развёртыванию](docs/DEPLOYMENT.md).

```bash
cp .env.example .env
# Заполните обязательные секреты в .env
docker compose -f compose.yaml -f compose.standalone.yaml up -d --build
docker compose -f compose.yaml -f compose.standalone.yaml ps
```

Для запуска без Telegram-бота добавьте `--scale telegram-bot=0` к команде `up`. Для локальной проверки без доменов и TLS используйте `compose.host-caddy.yaml`, который публикует Nginx только на `127.0.0.1:8088`. Команды, подготовка DNS, проверка API, обновление и резервное копирование приведены в [DEPLOYMENT.md](docs/DEPLOYMENT.md). Полный [список секретов и настроек](docs/SECRETS.md) отделяет обязательные значения от дополнительных.

## Вход в кабинеты

**Доступы для жюри:**

| Сайт | Логин | Пароль |
| --- | --- | --- |
| [Основная платформа](https://bashperevod.ru/) | Введите любой `username` от 3 до 20 символов | Не нужен |
| [Кабинет преподавателя (LMS)](https://lms.bashperevod.ru/) | `faclok` | `Fac5Lok4Fac5Lok4!` |
| [Кабинет эксперта](https://expert.bashperevod.ru/) | `admin` | `aA1!4fc1ff0ab99843900288230255f98530454f1b71` |

Основной сайт работает в демо-режиме с входом только по имени пользователя. LMS и экспертный кабинет используют общие аккаунты ядра, но входят с паролем. Для импорта CSV нужен доступ эксперта или администратора. После демонстрации публичные пароли, особенно пароль `admin`, следует сменить.

## Важные ограничения

Игровой интерфейс и серверная система переводов развивались параллельно; часть экранов использует собственное состояние и моковые данные. Не следует считать все показатели игрового профиля данными общего API. При переходе со старой базы аккаунты и переводы автоматически не мигрируют: перед подключением существующих пользователей нужен отдельный план переноса. Детали текущих контрактов изложены в [документации ядра](src/main-api/docs/INTEGRATION.md).
