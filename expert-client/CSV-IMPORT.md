# Загрузка CSV

В экспертном кабинете откройте **Загрузка CSV**. Поставщику данных доступен импорт; администратор может нажать **Включить загрузку для моего аккаунта**, чтобы назначить себе роль поставщика через штатный API управления доступом. Сервер проверяет права при каждом запросе. Роль эксперта сама по себе не разрешает загрузку.

1. Выберите CSV в UTF-8, до 25 МБ и 20 000 записей.
2. Проверьте первые пять записей и результаты проверки. Если есть ошибки, исправьте файл и выберите его снова.
3. Нажмите **Загрузить для проверки**. Прогресс показывает число обработанных записей. Кнопка остановки завершает текущий запрос и останавливает дальнейшую отправку. Уход с вкладки тоже останавливает дальнейшую отправку.

Обязательные колонки: `fragment_id`, `text_ba`, `text_ru`, `source_dataset`. Разделитель — запятая; поддерживаются BOM, CRLF, переносы строк и экранированные кавычки внутри значений. ID и имя источника — до 200 символов, оригинал и перевод — до 10 000. Повторяющиеся ID внутри файла блокируют импорт. Одинаковые пары текстов с разными ID сохраняются отдельно и показываются в счётчике повторов.

Загружается направление **ba-ru**. Каждая строка становится непроверенным кандидатом для существующего процесса проверки участниками. `quality_score` не создаёт экспертного решения или учебного материала. `source_dataset` сохраняется как ID документа, `attribution` — как название источника, остальные колонки (включая дополнительные языки, лицензию и оценку качества) — JSON в поле `source.chapter`. Сам CSV отдельно на сервер не сохраняется. Существующий API приёма помечает начальные варианты как машинные; отдельная классификация переводов из изданий пока отсутствует.

Записи отправляются последовательно через `POST /api/deliveries`. Ключ повтора определяется источником, внешним ID и направлением. Повтор файла **под тем же аккаунтом** безопасен: ядро возвращает прежний результат для неизменённых строк. Исправленное содержимое с прежним ключом вызывает конфликт; обновление существующего фрагмента этим импортом не поддерживается. После сетевой ошибки можно повторить файл; уже сохранённые строки сохраняются. Под другим аккаунтом поставщика сервер рассматривает данные как отдельную поставку.

Оценка качества и лицензия сохраняются как сведения поставщика, их достоверность импорт не проверяет.

## Локальный запуск и проверка

Из `src/expert-api`: `MAIN_API_URL` указывает на ядро; `PORT=5106`, затем `npm start`. Из `expert-client`: `npm run dev`; Vite направляет API-запросы на `http://127.0.0.1:5106` (можно переопределить через `EXPERT_API_URL`). В Compose используются существующие маршруты nginx.

`npm test` проверяет разбор CSV, валидацию строк и стабильность ключей повторной отправки. `npm run build` собирает кабинет.
