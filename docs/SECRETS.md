# Секреты и переменные окружения

Все переменные Compose задаются в локальном `.env` на сервере. Скопируйте [шаблон](../.env.example), замените примеры случайными значениями и ограничьте доступ к файлу (`chmod 600 .env`). `.env` исключён из Git. Не передавайте его в issue, логи, чат или публичный архив.

| Переменная | Когда нужна | Назначение |
| --- | --- | --- |
| `POSTGRES_PASSWORD` | Всегда | Пароль пользователя `app` для трёх баз PostgreSQL. Сохраните при обновлениях. |
| `JWT_SIGNING_KEY` | Всегда | Постоянный случайный ключ подписи токенов, минимум 32 байта UTF-8. Смена аннулирует активные сессии. |
| `BOOTSTRAP_USERNAME` | Первый запуск на пустой базе | Логин первого администратора; по умолчанию `admin`. |
| `BOOTSTRAP_PASSWORD` | Первый запуск на пустой базе | Пароль первого администратора. Нужен только для создания аккаунта; изменение переменной позднее не меняет пароль в базе. |
| `INTERNAL_API_KEY` | Всегда | Общий секрет взаимодействия ядра, LMS API и Telegram-бота. |
| `TELEGRAM_BOT_TOKEN` | Для запуска бота | Токен BotFather. При пустом значении используйте `--scale telegram-bot=0` в команде `up`. |
| `AUDIO_S3_ACCESS_KEY` | Если нужны аудиоупражнения | Ключ доступа к S3-совместимому хранилищу Garage. |
| `AUDIO_S3_SECRET_KEY` | Если нужны аудиоупражнения | Секретный ключ того же хранилища. |
| `TELEGRAM_HTTPS_PROXY` | Если нужен прокси | Адрес прокси для исходящих запросов бота; может включать учётные данные. |

Дополнительные настройки без секретов:

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_USERNAME` | Публичное имя бота без `@` для ссылки на него. |
| `STUDENT_PORTAL_URL` | Адрес страницы привязки Telegram, по умолчанию `https://bashperevod.ru/telegram.html`. |
| `BASHPEREVOD_HTTP_PORT` | Порт локального Nginx при `compose.host-caddy.yaml`, по умолчанию `8088`. |
| `CADDY_DOCKER_NETWORK` | Имя существующей сети Caddy при `compose.caddy-network.yaml`. |

## Пароли `expert` и `lms`

Отдельных паролей или `EXPERT_PASSWORD`/`LMS_PASSWORD` у сервисов нет. Оба кабинета отправляют логин и пароль в общее ядро (`/auth/sign-in`). Публичные демонстрационные доступы для жюри приведены в [README](../README.md#вход-в-кабинеты). Для учётной записи эксперта с импортом CSV нужны соответствующие права. На пустой базе первый администратор получает доступ из `BOOTSTRAP_USERNAME` и `BOOTSTRAP_PASSWORD`; на существующей базе используйте фактический пароль аккаунта, а не значение из `.env`.

Проверять заполненность секретов можно без вывода значений: `docker compose --env-file .env -f compose.yaml -f compose.standalone.yaml config --quiet`. Эта команда проверяет синтаксис Compose, но не силу паролей и не доступность внешних сервисов.
