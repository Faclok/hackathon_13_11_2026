# SCORM 1.2: вводный курс

Пакет содержит один SCO для первого курса (`courseId=1`). Учебный кабинет должен быть доступен по HTTPS на `lms.bashperevod.ru`. Перед загрузкой в другую LMS проверьте, что её импорт поддерживает SCORM 1.2 и разрешает открывать внешние сайты во фрейме.

Собрать архив из корня репозитория:

```bash
cd scorm
zip -q ../bashperevod-scorm-1.2.zip imsmanifest.xml index.html *.xsd
```

`imsmanifest.xml` и все XSD должны лежать в **корне** ZIP. XSD взяты из [набора схем SCORM 1.2](https://scorm.com/scorm-explained/technical-scorm/content-packaging/xml-schema-definition-files/) Rustici Software.

При запуске обёртка находит SCORM API, открывает учебный кабинет и принимает прогресс только от `https://lms.bashperevod.ru`. После входа в кабинет и завершения уроков она записывает процент в `cmi.core.score.raw`, а когда завершены все уроки — `passed` в `cmi.core.lesson_status`. Прогресс также хранится в PostgreSQL LMS сервиса. Пользователь входит в свой аккаунт Башперевода внутри кабинета; единый вход из внешней LMS здесь не реализован.

SCORM 1.2 является совместимым форматом для систем, которые поддерживают этот стандарт. Поддержка SCORM или LTI конкретным продуктом Яндекса не подтверждена его публичной документацией; перед подключением требуется спецификация и тестовый доступ к нужной системе. LTI 1.3 потребует отдельной регистрации платформы, OIDC запуска и, для передачи оценок, AGS.
