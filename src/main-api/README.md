# Башкирская языковая школа — C#-ядро

Стадия: реализован MVP C#-ядра на .NET 10 / ASP.NET Core / EF Core для школьных и самостоятельных участников: аккаунты и сессии, приём/выдача/принятия, большинство, экспертиза, доверие, экспорт и базовые учебные попытки. Проверки включают PostgreSQL, миграционное обновление и параллельные пересчёты. Подсчёт использует только последние принятия; самостоятельные аккаунты не подменяют школьный охват.

Запуск, согласованные в ходе реализации решения, проверки и ограничения: [IMPLEMENTATION.md](IMPLEMENTATION.md). Запросы внешним командам: [core.http](src/BashkirSchool.Host/core.http). Решение: [BashkirSchool.slnx](BashkirSchool.slnx).

Развёртывание: один [Dockerfile](Dockerfile), без Compose и Aspire. Контейнер получает подключение к PostgreSQL и секреты через конфигурацию, сам применяет миграции до запуска HTTP. На пустой базе создаёт администратора из Bootstrap:Username/Password; на повторных запусках существующие аккаунты не меняет.

В общем репозитории ядро находится в `src/main-api`; существующий корневой Compose подключает этот Dockerfile. Настройки запуска, маршруты прокси и договор с клиентом/LMS/ботом описаны в [docs/INTEGRATION.md](docs/INTEGRATION.md). Клиент и LMS адаптированы в коммите `c510a51`; прежний бот пока требует отдельной адаптации.

Для настройки контейнера: полный [appsettings.json](src/BashkirSchool.Host/appsettings.json), [шаблон переменных окружения](container.env.example) и [таблица обязательных значений и настроек по умолчанию](docs/INTEGRATION.md#непосредственно-в-контейнер-main-api). Секреты передаются окружением; пустые поля в appsettings не являются рабочими значениями.

**Для нового диалога и начала реализации: [START-HERE.md](START-HERE.md).** В нём последние решения, приоритет документов, порядок работы и готовый текст запроса.

## Распределение работ

Наша команда разрабатывает ядро с HTTP API и PostgreSQL. Веб, Telegram-бот и подготовка фрагментов/машинных переводов реализуются другими участниками и обращаются к ядру через API. В ядре нет Telegram webhook/FSM, распознавания аудио, парсинга и нарезки документов.

## Состояние проверки проекта

Пройден 51 тест без пропусков: школьный доступ, самостоятельная регистрация и восстановление администратором, ссылки и сессии, последние принятия, пороги/охват, экспертное закрытие, доверие, экспорт, учебные попытки и настоящий PostgreSQL, включая обновление и параллельные случаи. Точный объём и пределы — docs/VERIFICATION.md. Docker build и нагрузочная готовность отдельно не заявляются.

Временные установщики навыков, локальный переносимый Node.js, скачанные исходники навыков, снимки доски и устаревшие проектные документы удалены при очистке. Глобальные навыки и глобальный AGENTS.md находятся вне проекта и не изменялись. Для будущего использования команды npx потребуется доступный Node.js; он не является зависимостью проектируемого C#-ядра.
