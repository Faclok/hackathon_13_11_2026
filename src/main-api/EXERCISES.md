# Набор заданий main-api

Уточнение пользователя от 14 ноября 2026. Набор реализован в main-api; договор с клиентом, настройки Silero/MinIO и порядок добавления новых видов — [docs/EXERCISE-API.md](docs/EXERCISE-API.md). Проверка настоящего синтеза и эксплуатационные ограничения отмечаются отдельно в документации проверок.

## Согласованные виды

Актуальная организация обучения — [личные уровни](docs/LEVELS.md): 6–10 вопросов, ошибки возвращаются в конец очереди, все вопросы нужно решить правильно. Необязательный босс состоит из трёх фрагментов и доступен за каждые пять уровней. В новых уровнях все упражнения по фрагментам требуют определённого сообществом или экспертом перевода. Дневные маршруты удалены.

| Вид | Условие для клиента | Ответ клиента |
| --- | --- | --- |
| Сопоставление слов | Пять слов на одном языке и пять переводов на другом, в перемешанном порядке | Пять пар «слово — перевод» |
| Выбор перевода в обычном уровне | Предложение и три варианта; подчёркнутое слово открывает словарную подсказку, также доступен перевод всей фразы | Один выбранный вариант |
| Выбор перевода предложения — основной режим | Предложение и до четырёх самых популярных вариантов перевода; вариантов может быть меньше. Дополнительно доступен ввод своего варианта | Один выбранный вариант **либо** один собственный перевод |
| Подтверждение перевода | Предложение с одним показанным переводом | Подтверждение показанного перевода либо собственный перевод |
| Аудиодиктант | Озвучка и три варианта на языке записи; исходный текст открывается по нажатию | Один выбранный вариант |
| Перевод на слух | Озвучка и три варианта на целевом языке; исходный текст открывается по нажатию | Один выбранный вариант |
| Пропущенное слово | Предложение со случайно скрытым словом | Выбор слова из вариантов либо ввод слова |
| Сборка предложения | Перемешанные части предложения на башкирском языке | Части в порядке, восстанавливающем предложение |

Свой перевод — поле свободного ввода, а не пятый заранее подготовленный вариант. Выбор одного перевода не является выбором нескольких допустимых переводов одновременно.

## Ограничения материалов и ответов

- Проверка переводов собирает принятия и собственные формулировки по существующему TranslationCase. Самый популярный перевод не становится доказанно верным лишь из-за показа первым. Формула последних принятий и экспертное закрытие сохраняют смысл, описанный в CONSENSUS.md.
- Учебная попытка сама по себе не создаёт голос или вклад доверия. Для оценки перевода используются сохранённые допустимые формулировки соответствующей редакции результата.
- Предложения без перевода **не допускаются в перевод на слух**. Для учебной оценки действует существующее правило допуска: перевод принят сообществом или экспертом. Сам диктант проверяет исходный текст, перевод для его ответа не требуется.
- Для обоих аудиорежимов нужна готовая озвучка: создать её через TTS, загрузить в хранилище в окружении Coolify, затем выдать клиенту ссылку для прослушивания. Не выдавать аудиозадание до готовности файла.
- В диктанте исходный текст доступен пользователю по нажатию на плеер или подсказку. Правильные пары слов, скрытое слово и эталонный порядок частей не передаются как готовые ответы.
- Выдача сохраняет показанные варианты, перемешивание и ключ проверки; повторное получение не должно менять условие уже выданного задания. Клиент возвращает идентификаторы выбранных элементов или свой текст, сервер проверяет принадлежность элементов выдаче.
- Повторяющиеся слова/части в конструкторе различаются идентификаторами, чтобы каждое вхождение можно было использовать ровно один раз.

## Что уже есть в коде

- `ReviewWorkflow`: выдача одного перевода, Confirm/Correct/Skip; сохраняются принятия, действует распределение и пересчёт согласования.
- `LevelWorkflow`: текущий личный уровень, очередь вопросов и повтор ошибок, статистика попыток и необязательные боссы.
- `LevelQuestionResponse` содержит Kind, SchemaVersion и Prompt. Обработчики реестра создают публичные условия и приватные ключи; каждая попытка проверяется сохранённой версией обработчика.
- Добавлены пять словарных пар, до четырёх популярных переводов/свой текст, оба аудиорежима, пропущенное слово и сборка предложения. Учебные ответы отправляются только через текущий уровень; мнения о переводах используют отдельный процесс проверки.
- Озвучка: ленивый локальный worker `v5_cis_base` под управлением C#, кэш файлов модели, повторное использование аудио в S3/MinIO, подписанные ссылки для клиента. Без принятого перевода перевод на слух не создаётся.

## Детали, которые ещё не заданы

- Выбраны Silero `v5_cis_base`, WAV и S3/MinIO. Адрес MinIO, bucket и секреты нужно задать для конкретного развёртывания; значения не выдумываются.
- Источник словарных пар и допустимость неоднозначных переводов при сопоставлении.
- Реализация пропуска использует до четырёх разных слов из предложения/словаря; сборка режет по пробелам и сохраняет пунктуацию при словах. Это рабочие настройки реализации, не утверждённая лингвистическая политика подбора отвлекающих вариантов.
- Правила сравнения свободного ответа: регистр, пробелы, пунктуация и допустимые опечатки. Нынешнее буквальное сравнение не означает, что эти правила уже утверждены для диктанта.
- Распределение видов задаётся Learning:Kinds. Популярность использует последние принятия уникальных участников, равенства — время создания и ID. Эти технические правила выбора описаны в договоре с клиентом и могут быть изменены без подмены уже выданных снимков.

Игровая экономика остаётся отложенной. Этот набор не задаёт баллы и награды.
