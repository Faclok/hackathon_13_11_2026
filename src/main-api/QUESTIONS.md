# Оставшиеся вопросы и границы MVP

14 ноября 2026. Текущие правила голосов и доверия согласованы пользователем и описаны в [CONSENSUS.md](CONSENSUS.md). Старый перечень Q1–Q6 сохранён в Git-истории; он больше не должен блокировать реализованные процессы.

## Закрыто в текущем обсуждении

- Считаются только принятия, без отдельных отказов. Последнее принятие участника по случаю — его текущий голос.
- 85 человек за A и 15 за B дают 85%/15%; пропуски не входят в знаменатель.
- Исправление даёт один вклад доверия за предложенный текст, без дополнительного вклада за отклонение исходного.
- При потере определённости прежние вклады доверия сохраняются до нового определённого решения.
- Непринятый вариант не признаётся неверным автоматически; эксперт указывает неверные отдельно.
- Учителей/экспертов назначает администратор; учитель создаёт классы и учеников своей школы.
- .NET 10, PostgreSQL, один Dockerfile, автоматические миграции и bootstrap из секретов. Compose и Aspire не используются.
- Самостоятельная регистрация без школы: логин/пароль, общие принятия и N. Школы/классы не выдумываются, школьный охват и доли групп остаются обязательными. Восстановление пока только администратором после ручной проверки человека.

## Следующие продуктовые ветви

1. Автоматическое восстановление самостоятельного аккаунта через email/Telegram или резервный код не требуется в текущем этапе: пользователь выбрал административный процесс. При появлении этих каналов договор проверенного владения нужно согласовать отдельно.
2. Telegram-аттестация/привязка и пользовательская сессия бота. Сам бот находится вне ядра.
3. Подготовка данных: пакетные частичные результаты, версии исправленного оригинала, словарная интеграция и поддержка направлений. Текущая поставка — атомарный подготовленный фрагмент.
4. Расширенные учебные механики, пополнение урока, повторная практика и явное оспаривание из упражнения. Сейчас есть стабильный дневной урок с буквальной проверкой по сохранённым допустимым формулировкам; неизвестный текст возвращает Recognized=false и не объявляется лингвистически неверным.
5. Домены frontend/API, CORS и браузерный cookie-протокол обновления. Текущий refresh передаёт явный секрет в JSON, не создаёт ambient cookie; URL и JWT его не содержат. Долговременное хранение токена браузером не навязывается.
6. Эксплуатация: целевой сервер/registry, резервные копии, мониторинг, сроки хранения и нагрузочные пределы.

Игровые баллы, рейтинги, уровни и достижения остаются отложенными. Их правила не придуманы ради заполнения сущностей.

## Проверки

Проверки включают живой PostgreSQL: миграции/обновление, сохранение ключей после перезапуска, фоновые пересчёты и параллельные случаи. Матрица и ограничения — [docs/VERIFICATION.md](docs/VERIFICATION.md). Docker build в этой Windows-среде не выполнялся: Docker Engine не обнаружен.
