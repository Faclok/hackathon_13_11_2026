# Скины за уровни игрока

Это уровни профиля по опыту, а не учебные уровни `/api/learning/*`.
Существующее преобразование XP в уровень сохранено; новые источники и размеры начисления XP не добавлены.

`POST /api/player/level-rewards/claim` с авторизацией выдаёт награды за все достигнутые,
ещё не награждённые уровни, начиная со второго. Ответ: `{ profile, rewards }`.
Каждая награда содержит `level`, `decorationId`, `rarity`, `duplicate`, `compensation`.
Уровень и получателя определяет сервер, тело запроса не требуется.

- Обычная награда — на каждом новом уровне.
- Каждый 5-й уровень — редкая вместо обычной.
- Каждый 10-й — эпическая вместо редкой и обычной.
- Легендарные, стандартные и выведенные из обращения скины исключены.
- В первую очередь выбирается случайный неполученный скин нужной редкости.
  Если редкость собрана целиком, выдаётся дубликат с компенсацией 5 монет.

Выдача, инвентарь, компенсация и отметка последнего награждённого уровня сохраняются
одной транзакцией с общей блокировкой операций инвентаря. Повторный запрос возвращает
пустой `rewards` и не начисляет награды повторно. Новые профили на уровне 1 не получают
скин; существующие получают награды за ранее достигнутые уровни при первом запросе.

Клиент вызывает выдачу при входе и обновлении профиля. Полученные скины доступны
в обычном инвентаре, результаты выдачи отображаются в профиле до выхода/перезагрузки.
Для существующей базы требуется миграция `20261115120000_PlayerLevelRewards`.
