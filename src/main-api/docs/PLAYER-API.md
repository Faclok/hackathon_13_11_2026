# Игрок: профиль, награды, кейсы и рейтинг

Все маршруты требуют JWT участника. Состояние хранится в `PlayerStates`, открытия — в `PlayerCaseOpenings`; миграция `PlayerEconomy` добавляет эти таблицы без изменения данных переводов.

Модель объединена с личными уровнями миграцией `MergePlayerEconomyAndLevels`: она фиксирует общий снимок без повторного создания таблиц и удаления дневного архива. Статистика игрока и рейтинг учитывают правильные ответы `LevelAnswer`; ошибочные и повторные HTTP-отправки не увеличивают число решённых заданий.

| Маршрут | Назначение |
| --- | --- |
| `GET /api/player/profile` | Баланс, XP, уровень, серия, число заданий, награды, инвентарь и оформление |
| `GET /api/player/decorations` | ID, тип и редкость предметов каталога |
| `GET /api/player/cases` | Четыре кейса, состав и шансы выпадения |
| `POST /api/player/keys` `{ "quantity": 1 }` | Купить ключи по 10 монет |
| `POST /api/player/cases/{caseId}/open` | Потратить один ключ, выдать предмет или 3 монеты за дубль |
| `GET /api/player/cases/history` | Последние 50 открытий |
| `PUT /api/player/equipment/{itemId}` `{ "equipped": true }` | Надеть принадлежащий предмет |
| `GET /api/leaderboard?period=global&metric=tasks` | Рейтинг реальных участников; `period` = `global`/`monthly`, `metric` = `tasks`/`streak` |

За первый принятый ответ на обычный перевод за день участник получает 20 XP и 10 монет. За завершённый уровень в «Учить» начисляется целая часть количества вопросов, делённого на 3. Каждые пять завершённых уровней дают один накапливаемый Меч; он расходуется при начале Босса и показывается в профиле как `swords`. Каждый ответ Боссу приносит 1 монету; после решения большинства или эксперта правильный ответ приносит ещё 4 монеты. За первые три ответа Боссу также выдаются 100 XP и награда `boss`. Повторная отправка того же ответа не начисляет награду повторно.

`GET /api/boss/access` сохраняет поля `tasksSolved`, `streak`, `canAccess`, но доступ определяется накопленными возможностями за каждые пять пройденных уровней. `POST /api/boss/next` выдаёт очередное предложение того же необязательного босса, что и `/api/learning/boss`, с общим прогрессом из трёх разных фрагментов. Ответ через `/api/reviews/{id}/response` учитывается при возобновлении босса; первые три ответа дают ту же однократную награду. Условие 250 заданий/14 дней не применяется.

Новый участник получает 40 монет при самостоятельной регистрации через `POST /auth/register` или при создании аккаунта через временный `POST /auth/username`. Бонус сохраняется вместе с аккаунтом и не начисляется при повторном входе. Ранее созданным и школьным аккаунтам он не добавляется.

Каталог предметов повторяет ID, типы и редкости основного клиента. Из кейсов исключены предметы по умолчанию и снятые с выдачи старые питомцы. Вес редкости общий для уровня: 45/30/18/7, внутри уровня предметы равновероятны. Уровни без предметов исключаются из нормализации.

Основной клиент получает профиль, баланс, кейсы, инвентарь и рейтинг через эти маршруты. Изображения и описания предметов остаются статическим оформлением клиента; сервер определяет доступные ID, шансы, выпадение, владение и баланс. Экраны «Босс» и «Учить» пока сохраняют локальный сценарий и не синхронизируют свои награды с балансом сервера.

Временный вход `POST /auth/username` создаёт участника по username или открывает сессию существующему участнику. Аккаунты сотрудников через этот маршрут не проходят. Маршрут включается только при `Demo__UsernameLoginEnabled=true`; для основного Compose флаг выставлен. Это временная схема без проверки владения username.
