# `Controllers/Requests.cs`

[Открыть исходный файл](../../Controllers/Requests.cs)

## Назначение

Типы входных JSON запросов.

## Как работает

`Credentials` описывает регистрацию, `Login` — вход, `Submission` — подтверждение или исправление перевода, `TelegramStart` — имя пользователя бота.

## Что учитывать

Поля сделаны nullable, поскольку смысловая валидация выполняется в бизнес-сервисах; `TaskId` нужен для внутреннего Telegram маршрута.
