# `Controllers/HealthController.cs`

[Открыть исходный файл](../../Controllers/HealthController.cs)

## Назначение

Проверка работоспособности базы данных.

## Как работает

`GET /api/health` вызывает `CanConnectAsync()` у EF Core. Успех даёт 200 с `{status:"ok"}`, отсутствие подключения — 503.

## Что учитывать

Это инфраструктурный маршрут; он не проверяет внешние сервисы или качество данных.
