# `Controllers/ApiControllerBase.cs`

[Открыть исходный файл](../../Controllers/ApiControllerBase.cs)

## Назначение

Общий адаптер результатов бизнес-сервисов.

## Как работает

Метод `Respond` преобразует `ServiceResult` в ответы MVC: 200, 400, 401, 404 и 409, сохраняя тело ответа при его наличии.

## Что учитывать

Контроллеры не повторяют преобразование статусов и не зависят от внутренних деталей сервисов.
