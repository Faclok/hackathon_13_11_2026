# `.dockerignore`

[Открыть исходный файл](../.dockerignore)

## Назначение

Исключения для контекста сборки Docker.

## Как работает

Не отправляет локальные каталоги `bin` и `obj`, а также пользовательские файлы IDE (`*.user`) в Docker build.

## Что учитывать

Меньший контекст ускоряет сборку и не переносит локальные артефакты в образ.
