# `Program.cs`

## Назначение

Точка входа веб-сервиса.

## Как работает

Читает строку подключения и внутренний ключ, регистрирует EF Core, контроллеры и бизнес-сервисы. До приёма запросов применяет миграции и демонстрационные данные, затем подключает маршруты контроллеров.

## Что учитывать

Для `main-api` используется отдельная таблица истории миграций `__EFMigrationsHistory_Main`. Без `ConnectionStrings:Default` или `INTERNAL_API_KEY` сервис не запускается.
