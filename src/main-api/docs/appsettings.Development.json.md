# `appsettings.Development.json`

[Открыть исходный файл](../appsettings.Development.json)

## Назначение

Настройки приложения для режима Development.

## Как работает

Переопределяет уровни логирования при `ASPNETCORE_ENVIRONMENT=Development`.

## Что учитывать

Файл не содержит секретов. Значения объединяются с `appsettings.json` по стандартным правилам конфигурации ASP.NET Core.
