## Назначение

Сборка и запуск контейнера основного API.

## Как работает

На стадии SDK восстанавливаются зависимости и публикуется Release-сборка. В финальный образ ASP.NET копируется только опубликованное приложение.

## Что учитывать

Контейнер слушает порт 8080 и запускается от непривилегированного `APP_UID`; `libgssapi-krb5-2` требуется драйверу PostgreSQL.
