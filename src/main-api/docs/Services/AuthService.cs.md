# `Services/AuthService.cs`

[Открыть исходный файл](../../Services/AuthService.cs)

## Назначение

Бизнес-логика аккаунтов и профиля.

## Как работает

Проверяет формат регистрации, нормализует логин, хеширует пароль, выдаёт сессию, обрабатывает конфликт уникального логина и возвращает профиль с суммой баллов.

## Что учитывать

Вход сравнивает пароль через `Passwords.Verify`; неверные данные возвращают результат Unauthorized без раскрытия существования аккаунта.
