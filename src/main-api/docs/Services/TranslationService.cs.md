# `Services/TranslationService.cs`

[Открыть исходный файл](../../Services/TranslationService.cs)

## Назначение

Чтение и выгрузка подтверждённых переводов.

## Как работает

Соединяет `translations` с фрагментами и источниками, отдаёт JSON с разобранным полем `source` и формирует CSV с экранированием кавычек.

## Что учитывать

Экспорт содержит UTF-8 BOM для совместимости с табличными редакторами; незавершённые и спорные переводы не публикуются.
