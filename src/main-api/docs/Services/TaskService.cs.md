## Назначение

Назначение задания и согласование пользовательских переводов.

## Как работает

`Today` выбирает общий фрагмент для дня по московскому времени и создаёт запись задания для пользователя. `Submit` сохраняет ответ, один раз начисляет баллы и пересчитывает поддержку вариантов.

## Что учитывать

Для каждого пользователя учитывается последний ответ на фрагмент. Два независимых одинаковых ответа без ничьей дают статус `confirmed`; остальные состояния — `collecting` и `disputed`. Ответ, баллы и перевод коммитятся одной транзакцией.
