# `Services/CommunityService.cs`

[Открыть исходный файл](../../Services/CommunityService.cs)

## Назначение

Расчёт рейтинга сообщества.

## Как работает

Группирует `point_events` по пользователю, считает сумму баллов и число ответов, связывает результат с именами пользователей и возвращает первые 20.

## Что учитывать

Порядок: баллы по убыванию, число ответов по убыванию, имя по возрастанию.
