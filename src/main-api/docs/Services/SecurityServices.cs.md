# `Services/SecurityServices.cs`

[Открыть исходный файл](../../Services/SecurityServices.cs)

## Назначение

Вспомогательные операции с паролями, сессиями и внутренним ключом.

## Как работает

`Passwords` использует PBKDF2-SHA256 и случайную соль. `Sessions` выдаёт случайный bearer token, хранит только SHA-256 хеш и проверяет срок 30 дней. `Internal` сравнивает секретный заголовок в постоянное время.

## Что учитывать

Сырой bearer token возвращается только при создании сессии. Изменение формата пароля или токена требует учёта уже сохранённых записей.
