# `Services/TelegramService.cs`

[Открыть исходный файл](../../Services/TelegramService.cs)

## Назначение

Бизнес-операции Telegram пользователя.

## Как работает

Создаёт или обновляет профиль по Telegram ID, получает задание, передаёт ответ в общий `TaskService` и считает баллы.

## Что учитывать

Telegram ID и веб логин сейчас создают отдельные аккаунты. Отсутствующий пользователь или TaskId обрабатываются без изменения базы.
