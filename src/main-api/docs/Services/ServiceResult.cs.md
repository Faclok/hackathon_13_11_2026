# `Services/ServiceResult.cs`

[Открыть исходный файл](../../Services/ServiceResult.cs)

## Назначение

Независимый от MVC результат бизнес-операции.

## Как работает

`ServiceStatus` перечисляет допустимые исходы, а `ServiceResult` хранит статус и необязательное тело. Статические фабрики упрощают создание результата.

## Что учитывать

`ApiControllerBase` сопоставляет эти исходы с HTTP кодами.
