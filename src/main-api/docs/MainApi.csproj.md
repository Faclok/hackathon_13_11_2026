# `MainApi.csproj`

[Открыть исходный файл](../MainApi.csproj)

## Назначение

Параметры сборки проекта ASP.NET Core.

## Как работает

Целевая платформа — .NET 10. Проект включает Npgsql, EF Core для PostgreSQL и инструментальный пакет EF Core Design.

## Что учитывать

Пакет Design помечен `PrivateAssets=all`: он нужен разработчику для миграций, но не транзитивным потребителям проекта.
