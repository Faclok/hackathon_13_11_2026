# Открытое API проверенных заданий

Заданием здесь считается кейс перевода с действующим экспертным решением. API отдаёт только кейсы, закрытые экспертом, включая импортированные наборы, отмеченные как проверенные. JWT не требуется.

| Метод | Маршрут | Результат |
| --- | --- | --- |
| GET | `/api/public/verified-tasks?offset=0&limit=20` | Список; `limit` от 1 до 100 |
| GET | `/api/public/verified-tasks/random` | Случайное проверенное задание |
| GET | `/api/public/verified-tasks/{caseId}` | Задание по ID; 404 для непроверенного кейса |
| POST | `/api/public/verified-tasks/{caseId}/tts` | Подготовить или переиспользовать аудио; возвращает объект `tts` |

Карточка содержит ID кейса и фрагмента, внешний ID, исходный текст, направление перевода, исходные метаданные `source`, дату и ревизию, экспертное решение с основным переводом и принятыми/отклонёнными ID, все варианты перевода, а также `tts` с языком, голосом, частотой, ID аудио, типом файла и `audioUrl`. Идентификаторы и данные участников не публикуются.

При первом чтении `tts.audioUrl` может быть `null`. `POST .../tts` синтезирует речь исходного текста через Silero и сохраняет WAV в настроенном объектном хранилище. Повторный запрос использует сохранённый файл. `audioUrl` — временная подписанная ссылка; после её истечения повторите GET карточки. На создание аудио действует ограничение 5 запросов в минуту на IP; превышение даёт 429. Непроверенные и несуществующие кейсы дают 404 и не запускают синтез.
