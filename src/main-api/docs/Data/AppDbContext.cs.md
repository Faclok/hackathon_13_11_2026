# `Data/AppDbContext.cs`

[Открыть исходный файл](../../Data/AppDbContext.cs)

## Назначение

EF Core модель основной базы.

## Как работает

Задаёт `DbSet` для пользователей, сессий, источников, фрагментов, кандидатов, заданий, ответов, переводов и начислений. `OnModelCreating` задаёт таблицы, ключи, индексы, связи и значения по умолчанию.

## Что учитывать

Имена столбцов переводятся в snake_case. `translations` имеет составной ключ `(fragment_id, lang_pair)`, а `source` хранится в PostgreSQL JSONB.
