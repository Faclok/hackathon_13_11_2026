# `Data/DemoSeed.cs`

[Открыть исходный файл](../../Data/DemoSeed.cs)

## Назначение

Начальные демонстрационные данные.

## Как работает

Если источников ещё нет, в одной транзакции создаёт демонстрационный источник, башкирские фрагменты и русские кандидаты перевода.

## Что учитывать

Кандидаты не считаются голосами пользователей. Наполнение не повторяется в базе, где уже есть хотя бы один источник.
