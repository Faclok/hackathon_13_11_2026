# `Data/AppDbContextFactory.cs`

[Открыть исходный файл](../../Data/AppDbContextFactory.cs)

## Назначение

Фабрика контекста для команд `dotnet ef`.

## Как работает

Создаёт `AppDbContext` без запуска веб-сервиса. Берёт строку подключения из `ConnectionStrings__Default`, иначе использует локальное значение для разработки.

## Что учитывать

Фабрика указывает ту же таблицу истории миграций, что и `Program.cs`, чтобы команды EF работали с правильной схемой.
