## Назначение

Первая миграция базы основного API.

## Как работает

`Up` создаёт таблицы пользователей, сессий, источников, фрагментов, кандидатов, заданий, ответов, решений и начислений с ключами и индексами. `Down` удаляет их в обратном порядке зависимостей.

## Что учитывать

Миграция отражает исходную схему и не должна переписываться после применения; изменения оформляются новыми миграциями.
