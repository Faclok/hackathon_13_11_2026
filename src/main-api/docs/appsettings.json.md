# `appsettings.json`

[Открыть исходный файл](../appsettings.json)

## Назначение

Базовые настройки ASP.NET Core.

## Как работает

Задаёт уровни логирования и разрешённые имена хостов. Конфигурация применяется во всех окружениях, если не перекрыта другими источниками.

## Что учитывать

Секреты и строка подключения не хранятся в этом файле; они приходят из переменных окружения.
